1) Войдите под созданным обычным пользователем.
2) Откройте Terminal через меню приложений.
3) Проверьте пользователя: whoami.
Ожидается ваше имя, а не root.
4) Проверьте право sudo: sudo -v.
Введите пароль пользователя, символы при вводе не отображаются.
5) Обновите индекс пакетов: sudo apt update.
6) Установите инструменты курса одной командой: sudo apt install -y openssh-server strace netcat-openbsd ufw.
7) Проверьте результат: ssh -V, strace -V и nc -h.
Команда nc -h может завершиться справочным сообщением, это нормальная проверка наличия программы.
8) Включите SSH-сервис: sudo systemctl enable --now ssh.
Затем выполните systemctl is-active ssh. Ожидаемый ответ: active.
9) Проверьте firewall: sudo ufw status.
До урока по firewall ожидается Status: inactive.
Не выполняйте ufw enable заранее.
